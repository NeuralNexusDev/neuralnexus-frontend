# Test plan: errors

## errors.go

| ID | Function | Scenario Type | Scenario | Precondition | Expected Result | Priority | Notes |
|----|----------|---------------|----------|---------------|------------------|----------|-------|
| ER-01 | `writeError` | Error Path | A 401 redirects to the login page and runs nothing else | `pageFail` of an error wrapping `errUnauthorized`, with `clearStatus`, `restore` and a `restoreLater` that records its call | Status 401, `HX-Redirect` `/login`, empty body, no `HX-Retarget` or `HX-Reswap`, the `restoreLater` function not called and nothing logged | P0 | |
| ER-02 | `writeError` | Error Path | A 4xx keeps its status and message and is not logged | `apiError{Status: 404, Message: "User not found"}` | Status 404, `HX-Retarget` `#page-error`, `HX-Reswap` `innerHTML`, `Content-Type` `text/html; charset=utf-8`, body exactly `User not found`, nothing logged | P0 | |
| ER-03 | `writeError` | Error Path | A 5xx keeps its status and message and is logged with the request, call and cause | `apiError{Status: 502, Message: "Failed to load roles", Method: "GET", Path: "/roles", Err: "connection refused"}` on a request with ID 77 | Status 502 with the three failure headers and the message as body; the log has `request failed`, `request_id=77`, `status=502`, `api="GET /roles"` and `cause=connection refused` | P0 | |
| ER-04 | `writeError` | Error Path | An error that is not an API error answers 500 with the fallback and is logged | `errors.New("boom")` | Status 500 with the failure headers and body `Something went wrong`, without `boom`; the log has `status=500`, an empty `api` and `cause=boom` | P0 | |
| ER-05 | `writeError` | Edge Case | A 5xx on a cancelled request is not logged | `apiError{Status: 502}` on a request whose context is cancelled | Status 502 and nothing logged | P1 | The body is empty because templ stops rendering on a cancelled context |
| ER-06 | `writeError` | Edge Case | An API error wrapped by the caller still gives its status and message | `fmt.Errorf("saving: %w", apiError{Status: 403, Message: "Forbidden"})` | Status 403, body `Forbidden` | P1 | |
| ER-07 | `(*pageError).clearStatus` | Happy Path | clearStatus adds an empty status line after the message | `pageFail(409 error).clearStatus("role-status")` | Body holds the message and then `<p id="role-status" hx-swap-oob="innerHTML"></p>` | P0 | |
| ER-08 | `(*pageError).restore` | Happy Path | Restore parts follow the message in the order given, across calls | `restore(first, second).restore(third)` | The body holds the message and then `first`, `second` and `third` in that order | P0 | |
| ER-09 | `(*pageError).flagField` | Happy Path | The flagged field is added for 400, 409 and 422 with the API message | Error with Status 400, 409 and 422 and message `Bad name`; `flagField` building a component from the message | Status as given, and the body holds the component built with `Bad name` | P0 | Table-driven over the statuses |
| ER-10 | `(*pageError).flagField` | Edge Case | The flagged field is left out for other statuses and for a non-API error | Errors with Status 403, Status 500 and a plain error | The body has no flagged field | P0 | Table-driven over the three errors |
| ER-11 | `(*pageError).restoreLater` | Edge Case | restoreLater builds its parts once, after the other parts | `restoreLater` counting its calls plus a `restore` part | One call; the `restore` part comes before the late part in the body | P1 | |
| ER-12 | `(*pageError).afterWrite` | Happy Path | afterWrite puts the explanation before the message and keeps the status | `pageFail(apiError{Status: 502, Message: "Failed to load roles"}).afterWrite()` | Status 502, body `The change was made, but the page could not be refreshed: Failed to load roles` | P0 | |
| ER-13 | `(*pageError).afterWrite` | Error Path | afterWrite leaves a 401 as a login redirect | `pageFail(errUnauthorized).afterWrite()` | Status 401, `HX-Redirect` `/login`, empty body | P0 | |
| ER-14 | `(*pageError).afterWrite` | Edge Case | The log line of an afterWrite failure keeps the original call and the plain cause | A 502 `apiError` with Method GET, Path `/roles` and cause `connection refused`, after `afterWrite()` | The log has `api="GET /roles"` and `cause=connection refused` and not the explanation | P1 | |
| ER-15 | `pageFail` | Edge Case | pageFail returns the pageError it is given, also when wrapped | A `pageError` and the same wrapped with `%w` | The same pointer comes back both times | P1 | |
| ER-16 | `pageFail` | Edge Case | The cause stays reachable through the pageError | `pageFail` of a wrapped `apiError`; of a wrapped `errUnauthorized`; of a plain error | `errors.As` finds the `apiError`; `unauthorized` is true only for the second | P1 | |
| ER-17 | `pageRoute` | Error Path | A returned error becomes the failure response | Handler returns `apiError{Status: 404, Message: "Not found"}` | Status 404 with the failure headers and body `Not found`, and `Cache-Control` set to `noStore` | P0 | |
| ER-18 | `pageRoute` | Edge Case | A handler that returns nil keeps its own response | Handler writes 418 and returns nil | Status 418, no `HX-Retarget` and an empty body | P1 | |
| ER-19 | `pageAction` | Error Path | A form that cannot be read answers 400 and skips the handler | POST with `HX-Request` and query `a=%zz` | Status 400 with the failure headers and body `The form could not be read`; handler not called | P0 | |
| ER-20 | `pageAction` | Error Path | A request without HX-Request is refused and skips the handler | POST without `HX-Request` | Status 403; handler not called | P0 | |
| ER-21 | `pageHandler.ServeHTTP` | Edge Case | The handler gets a request that ends at the page time limit | `pageRequestTimeout` set to 50ms (restored in `t.Cleanup`); handler waits for its context to end | The request context has a deadline and ends with `context.DeadlineExceeded` | P1 | Tests that swap `pageRequestTimeout` cannot use `t.Parallel` |
| ER-22 | `pageHandler.ServeHTTP` | Happy Path | The session handed to the handler carries the request it was given | Handler records the request and the request held by its `apiSession` | They are the same request, so the API calls use its cookie and its deadline | P1 | |
| ER-23 | `writeError` | Edge Case | The log line holds neither the session cookie nor the submitted form | A POST with the body `password=hunter2` and a session cookie `secret-session-value`; a 500 `apiError` with a cause | The failure is logged, and the log holds neither `secret-session-value` nor `hunter2` | P0 | The line is built from the request ID, the status, the API call and the cause only |
| ER-24 | `pageHandler.ServeHTTP` | Error Path | A handler stuck on a slow API is answered with 502 at the time limit | `pageRequestTimeout` set to 50ms (restored in `t.Cleanup`); the fake API holds `GET /roles` until the request ends; the handler returns the error of `apiGet` with the fallback `Failed to load roles` | Status 502 within two seconds, and the log holds `status=502` | P0 | The body is empty because the context has ended and templ stops rendering, as in ER-05. Tests that swap `pageRequestTimeout` cannot use `t.Parallel` |
