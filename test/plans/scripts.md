# Test plan: scripts

This plan covers 12 of the 26 functions of public/js/scripts.js: `apiBaseUrl`, `showAuthErrorFromQuery`, `steamOpenIdLoginUrl`, `sharedHostSuffix`, `setNonceCookie`, `createNonce`, `checkHeaderAuthState`, `logout`, `submitLoginForm`, `encodeState`, `buildSteamOpenIDURL` and `startOAuthLogin`. The other 14 are not in it. Thirteen belong to the mcstatus lookup page (`isDotSegment` is one of them) and get their plan in step 5 (prefix MP), and `handleLinkAction` has its tests in account.spec.js and moves with it in step 3.

The tests are in test/js/tests/scripts.spec.js. Each title starts with its row ID, so `--grep SC-07` runs one row. A row with several cases is a loop of tests, and every title in the loop starts with the row ID. The API is `page.route` mocks unless a row says otherwise, and the Go server serves the pages.
