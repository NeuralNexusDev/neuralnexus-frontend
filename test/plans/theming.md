# Test plan: theming

public/js/theming.js has three functions and some code that runs when the script loads. The tests are in test/js/tests/theming.spec.js, and each title starts with its row ID. The stored preference is set with `page.addInitScript` before the page loads, and the system colour scheme with `page.emulateMedia`. The header's `GET /users/me` is answered 401 by a route, since the header is not under test. The toggle is the header button that calls `toggleTheme()`.

## public/js/theming.js

| ID | Function | Scenario Type | Scenario | Precondition | Expected Result | Priority | Notes |
|----|----------|---------------|----------|---------------|------------------|----------|-------|
| TH-01 | `getThemePreference` | Happy Path | A stored light or dark wins over the system | `/`; `theme` stored as `light` with a dark system, then `dark` with a light system | `getThemePreference()` returns `light`, then `dark` | P0 | A loop of 2 tests |
| TH-02 | `getThemePreference` | Happy Path | With nothing stored it follows the system | `/`; nothing stored; a light system, then a dark system | `light`, then `dark` | P0 | A loop of 2 tests |
| TH-03 | `getThemePreference` | Edge Case | A stored value that is not light or dark follows the system | `/`; `theme` stored as `system` with a light system, then as `blue` with a dark system | `light`, then `dark` | P1 | A loop of 2 tests. `system` is the value the function treats as the default |
| TH-04 | `saveThemePreference` | Happy Path | It stores the preference under theme and a second call replaces it | `/`; nothing stored; `saveThemePreference('dark')`, then `saveThemePreference('light')` | `localStorage` `theme` is null, then `dark`, then `light` | P0 | |
| TH-05 | `toggleTheme` | Happy Path | From light it turns dark, shows the light icon and stores dark | `theme` stored as `light`; `/`; the click on the toggle | Before: `html` has no `dark` class, `#light-mode` is hidden and `#dark-mode` is visible. After: `html` has the `dark` class, `#light-mode` is visible, `#dark-mode` is hidden, and `theme` is `dark` | P0 | The visible icon is the one that switches to the other theme |
| TH-06 | `toggleTheme` | Happy Path | From dark it turns light, shows the dark icon and stores light | `theme` stored as `dark`; `/`; the click on the toggle | Before: the `dark` class, `#light-mode` visible, `#dark-mode` hidden. | TH-07 | `toggleTheme` | Edge Case | With nothing stored it turns a light system dark and a dark system light, and stores that | `/`; nothing stored; a light system, then a dark system; the click on the toggle | The `dark` class is present and `theme` is `dark`, then the class is absent and `theme` is `light` | P0 | A loop of 2 tests. The first toggle has no stored value to start from |
| TH-08 | `toggleTheme` | Edge Case | Two toggles end where they began, and the choice survives a reload | A light system, nothing stored; `/`; toggle, reload, toggle, reload | After the first toggle and its reload the page is dark with the light icon; after the second toggle and its reload it is light with the dark icon and `theme` is `light` | P0 | |
| TH-09 | `toggleTheme` | Happy Path | The page colours follow the class | `theme` stored as `light`; `/`; toggle twice | The computed background colour of `body` differs after the first toggle and is back to the first value after the second | P1 | Only a render shows that the class reaches the stylesheet |
| TH-10 | load-time setup | Happy Path | A stored light gives a light page with the dark icon, whatever the system | `theme` stored as `light`, a dark system; `/` | No `dark` class on `html`, `#light-mode` hidden, `#dark-mode` visible | P0 | |
| TH-11 | load-time setup | Happy Path | A stored dark gives a dark page with the light icon, whatever the system | `theme` stored as `dark`, a light system; `/` | The `dark` class on `html`, `#light-mode` visible, `#dark-mode` hidden | P0 | |
| TH-12 | load-time setup | Happy Path | With nothing stored a light system gives a light page and a dark system a dark page, and nothing is stored | Nothing stored; a light system, then a dark system; `/` | The class and the icons as TH-10, then as TH-11; `theme` is still null | P0 | A loop of 2 tests. Loading never writes the preference |
| TH-13 | load-time setup | Edge Case | The dark class is set by the time the document has loaded | `theme` stored as `dark`; a `DOMContentLoaded` listener added before the page scripts records whether `html` has the class | The recorded value is true | P1 | The icons are set later, on `load`. The class is set while the script runs in the head, so the page does not flash light first |
