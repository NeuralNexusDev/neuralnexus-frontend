# Test plan: api

## api.go

| ID | Function | Scenario Type | Scenario | Precondition | Expected Result | Priority | Notes |
|----|----------|---------------|----------|---------------|------------------|----------|-------|
| AP-01 | `(*apiError).Error` | Accessor | Error returns only the user-facing message | `apiError{Status: 502, Message: "Failed to load roles", Method: "GET", Path: "/roles", Err: errors.New("dial tcp 10.0.0.1:443 refused")}` | `Error()` is exactly `"Failed to load roles"`, with no method, path, status or cause text | P1 | Callers show this string to the user (`(*pageError).statusMessage` in errors.go) |
| AP-02 | `(*apiError).Unwrap` | Accessor | Unwrap returns the stored cause | `apiError{Err: cause}` with a sentinel `cause` | `errors.Unwrap(e) == cause`, `errors.Is(e, cause)` is true and `errors.Is(e, errUnauthorized)` is false | P1 | |
| AP-03 | `(*apiError).Unwrap` | Edge Case | Unwrap with no cause returns nil | `apiError{Status: 404, Message: "x"}` with `Err` nil | `errors.Unwrap(e)` is nil | P1 | errors.go `logFailure` walks the Unwrap chain until nil to log the root cause, so a nil here must end the walk (learned from reading that caller) |
| AP-04 | `invalidInput` | Happy Path | invalidInput builds a 400 apiError with the given message | `invalidInput("The form could not be read")` | `errors.As` finds `*apiError` with Status 400, Message `"The form could not be read"`, empty Method and Path, nil Err, and `Error()` returns the message | P1 | |
| AP-05 | `apiSession.call` | Happy Path | GET returns the response body unchanged | API answers 200 with `{"a":1}`; `call("GET", "/roles", nil, fallback)` | Returned bytes equal `{"a":1}` and error is nil; the API saw method GET and request URI `/api/v1/roles` | P1 | Tests point the exported var `config.APIURL` at the fake API and restore it in `t.Cleanup`, so they cannot use `t.Parallel`. The package needs `NN_API_URL` and `NN_SITE_URL` exported at init |
| AP-06 | `apiSession.call` | Edge Case | A query string in the path reaches the API intact | `call("GET", "/users?limit=50&offset=100", nil, fallback)` | API saw request URI `/api/v1/users?limit=50&offset=100` | P1 | |
| AP-07 | `apiSession.call` | Happy Path | A body is sent as JSON with the matching headers | `call("POST", "/roles", map[string]string{"name": "mod"}, fallback)` | API saw method POST, body JSON-equal to `{"name":"mod"}`, `Content-Type` `application/json` and `Accept` `application/json` | P1 | |
| AP-08 | `apiSession.call` | Edge Case | A nil body sends no body and no Content-Type | `call("DELETE", "/roles/1", nil, fallback)` | API read an empty body and saw no `Content-Type` header, and saw `Accept` `application/json` | P1 | |
| AP-09 | `apiSession.call` | Happy Path | The incoming session cookie is forwarded to the API | Incoming request carries cookie `session=abc123` | API saw exactly one cookie, named `session` with value `abc123` (the `Cookie` header is `session=abc123`) | P0 | |
| AP-10 | `apiSession.call` | Edge Case | Other cookies and credentials of the incoming request do not reach the API | Incoming request carries `session=abc123`, `theme=dark`, `csrf=x` and an `Authorization: Bearer t` header | API saw `Cookie` equal to `session=abc123` only and no `Authorization` header | P0 | |
| AP-11 | `apiSession.call` | Edge Case | No session cookie means no Cookie header | Incoming request has no cookies, then a variant with only `theme=dark` | API saw no `Cookie` header in both variants and the call still returns the body | P0 | |
| AP-12 | `apiSession.call` | Error Path | The session cookie is not sent to another host the API redirects to | API answers 302 with `Location` `http://other.test/x`; a second fake host `other.test` answers 200 and records its request | `other.test` saw no `Cookie` header | P1 | The second host must have a different host name (for example `localhost` against `127.0.0.1`). The production `apiClient` is used unchanged, so this guards against someone adding a redirect policy or a cookie jar to it |
| AP-13 | `apiSession.call` | Edge Case | The shared client has the 15 second timeout and no cookie jar | Read `apiClient` as built at package init | `apiClient.Timeout == 15*time.Second` and `apiClient.Jar == nil` | P1 | The 15 second timeout cannot be exercised without waiting 15 seconds, so only the configured value is asserted. Tests that swap `apiClient` restore it in `t.Cleanup` |
| AP-14 | `apiSession.call` | Error Path | A server that never answers ends the call with a timeout error | `apiClient` swapped for a copy with `Timeout` of 100ms (restored in `t.Cleanup`); handler blocks until the test releases it | `*apiError` with Status 502, Message equal to the fallback, the call's Method and Path, and `Err` satisfying `net.Error` with `Timeout()` true | P0 | Tests the mapping of a timeout, not the 15 second value (see AP-13). The production client cannot be made to time out sooner without changing the source |
| AP-15 | `apiSession.call` | Error Path | A body that cannot be JSON-encoded fails before any request | Body is `make(chan int)` | `*apiError` with Status 500, Message equal to the fallback, the call's Method and Path, `Err` a `*json.UnsupportedTypeError`, and the fake API saw zero requests | P2 | Handlers pass maps or structs, so this input cannot occur behind the auth check. |
| AP-16 | `apiSession.call` | Error Path | A request that cannot be built fails before any request | Method `"BAD METHOD"`, then path `"/x\ny"` | `*apiError` with Status 502, Message equal to the fallback, the call's Method and Path, non-nil `Err`, and the fake API saw zero requests | P2 | Handlers escape IDs and use fixed methods, so this input cannot occur behind the auth check. Table-driven over the two inputs |
| AP-17 | `apiSession.call` | Error Path | Canceling the incoming request cancels the in-flight API call | Handler signals that it received the request and then blocks; the test cancels the request context | The call returns `*apiError` with Status 502, Message equal to the fallback and `errors.Is(err, context.Canceled)` true, without waiting for the client timeout | P1 | Uses a channel from the handler as the signal, no sleep |
| AP-18 | `apiSession.call` | Error Path | An unreachable API maps to 502 with the fallback message | `config.APIURL` points at a fake API server that has been closed | `*apiError` with Status 502, Message equal to the fallback, the call's Method and Path and non-nil `Err`; `Error()` does not contain the server address or the transport error text | P0 | |
| AP-19 | `apiSession.call` | Error Path | A response body that breaks mid-read maps to 502 | API sends status 200, header `Content-Length: 100`, writes 10 bytes and closes the connection | `*apiError` with Status 502, Message equal to the fallback, the call's Method and Path and `Err` that is `io.ErrUnexpectedEOF` | P0 | Needs a real listener, not a recorder, to cut the connection |
| AP-20 | `apiSession.call` | Error Path | A 401 maps to the errUnauthorized sentinel | API answers 401 with an empty body, then with `{"detail":"Token expired"}`, then with an HTML body | Returned error `== errUnauthorized` in every case, `errors.As` to `*apiError` is false and the returned bytes are nil | P0 | Table-driven over the three bodies |
| AP-21 | `apiSession.call` | Error Path | A 4xx with a detail message carries that detail, not the fallback | API answers each of 400, 403, 404, 409 and 422 with `{"detail":"Role name taken"}`; fallback `"Failed to save the role"` | `*apiError` with the same Status, Message `"Role name taken"`, the call's Method and Path, and nil `Err` (so `errors.Unwrap` is nil) | P0 | Table-driven over the status codes. 400 is the lowest status treated as an error |
| AP-22 | `apiSession.call` | Error Path | A 5xx with a detail message carries that detail | API answers each of 500, 502 and 503 with `{"detail":"database down"}` | `*apiError` with the same Status, Message `"database down"`, the call's Method and Path and nil `Err` | P0 | Table-driven over the status codes |
| AP-23 | `apiSession.call` | Edge Case | An error status without a usable detail falls back to the fallback message | API answers 404 and 503 with each of an empty body, plain text, an HTML page, JSON without `detail`, `{"detail":""}`, `{"detail":null}`, `{"detail":[{"msg":"bad"}]}` (a list) and `{"detail":42}` | `*apiError` with the answered Status and Message equal to the fallback, in every combination | P0 | Table-driven over statuses and bodies |
| AP-24 | `apiSession.call` | Error Path | The fallback is ignored for a 401 | Non-empty fallback `"Failed to load roles"`; API answers 401 | `err.Error()` is `"not signed in"` and does not contain the fallback | P0 | |
| AP-25 | `apiSession.call` | Edge Case | An empty fallback with no detail gives an empty message | Fallback `""`; API answers 500 with an empty body | `*apiError` with Status 500 and empty Message; `Error()` returns `""` | P2 | |
| AP-26 | `apiSession.call` | Edge Case | Success statuses without a JSON body return the body bytes and no error | API answers 201 with `{"id":1}`, then 204 with no body | First call returns `{"id":1}`; second returns zero bytes; both with nil error | P1 | Table-driven over the two answers |
| AP-27 | `apiSession.call` | Edge Case | A response over 1 MiB is cut at 1 MiB | API answers 200 with 1048576 + 100 bytes | Returned length is exactly 1048576 and error is nil | P1 | |
| AP-28 | `apiSession.call` | Edge Case | The response body is closed on success and on an error status | Transport wrapper counts `Close` on the response body; API answers 200, then 500 | `Close` was called once for each call | P2 | Needs `apiClient` swapped for a copy whose Transport wraps the response body to record Close |
| AP-29 | `apiSession.call` | Concurrency Invariant | Concurrent calls never mix up session cookies | 20 goroutines each call with their own request holding `session=s-<i>` against an API that echoes the received cookie in the response body | Every call returns the body containing its own `s-<i>` and no other | P0 | Run with the race detector. A fault injection that stores the cookie in shared state must fail this test |
| AP-30 | `apiGet` | Happy Path | apiGet decodes a JSON response into T | API answers 200 with `{"name":"mod"}` for a struct T, then `["a","b"]` for `[]string` | First returns the struct with `Name` `"mod"`, second returns `["a","b"]`, both with nil error; API saw method GET, no body and no `Content-Type` | P1 | |
| AP-31 | `apiGet` | Error Path | A 401 passes through as errUnauthorized with a zero value | API answers 401, T is `[]string` | Error `== errUnauthorized` and the result is a nil slice | P0 | |
| AP-32 | `apiGet` | Error Path | An error status from the API passes through unchanged with a zero value | API answers 404 with `{"detail":"Role not found"}`, T is a struct | `*apiError` with Status 404, Message `"Role not found"`, Method GET and the call's Path, and a zero struct | P0 | |
| AP-33 | `apiGet` | Error Path | A 200 body that does not decode maps to 502 | API answers 200 with `not json`, then with `{"a":1}` for T `[]string` | `*apiError` with Status 502, Message equal to the fallback, Method GET, the call's Path and `Err` a `*json.SyntaxError` (first) or `*json.UnmarshalTypeError` (second) | P0 | Table-driven over the two bodies |
| AP-34 | `apiGet` | Edge Case | An empty 200 body is a decode failure | API answers 200 with no body | `*apiError` with Status 502, Message equal to the fallback, Method GET and non-nil `Err` | P0 | Differs from `apiSend`, which accepts an empty body |
| AP-35 | `apiGet` | Edge Case | A JSON body over 1 MiB fails to decode because it is cut | API answers 200 with a valid JSON string array longer than 1048576 bytes, T is `[]string` | `*apiError` with Status 502, Message equal to the fallback and non-nil `Err` | P1 | |
| AP-36 | `apiSend` | Happy Path | apiSend sends the method and JSON body and decodes the response | PUT, PATCH and POST each with body `{"name":"mod"}`; API answers 200 with `{"id":7}` for a struct T | Returned struct has `ID` 7 with nil error; API saw the given method, JSON-equal body and `Content-Type` `application/json` | P1 | Table-driven over the three methods |
| AP-37 | `apiSend` | Edge Case | An empty or whitespace-only response gives a zero value and no error | DELETE with nil body; API answers 204 with no body, then 200 with `"  \n"` | Zero value of T and nil error in both cases; API saw no `Content-Type` | P1 | Table-driven over the two answers |
| AP-38 | `apiSend` | Error Path | A 2xx body that does not decode maps to 502 with the caller's method | PATCH; API answers 200 with `not json`, then with `[1]` for a struct T | `*apiError` with Status 502, Message equal to the fallback, Method `PATCH` (not GET), the call's Path and `Err` a `*json.SyntaxError` (first) or `*json.UnmarshalTypeError` (second) | P0 | Table-driven over the two bodies |
| AP-39 | `apiSend` | Error Path | A 401 passes through as errUnauthorized with a zero value | POST; API answers 401 | Error `== errUnauthorized` and the result is the zero value of T | P0 | |
| AP-40 | `apiSend` | Error Path | An error status from the API passes through unchanged with a zero value | POST; API answers 409 with `{"detail":"Role name taken"}` | `*apiError` with Status 409, Message `"Role name taken"`, Method POST and the call's Path, and a zero value | P0 | |
| AP-41 | `apiSend` | Error Path | A body that cannot be encoded fails before any request | POST with body `make(chan int)` | `*apiError` with Status 500, Message equal to the fallback, Method POST and the call's Path; the fake API saw zero requests | P2 | Handlers pass maps or structs, so this input cannot occur behind the auth check. |
