# Test plan: mcstatus lookup page

This plan covers the 13 mcstatus functions of public/js/scripts.js: `isDotSegment`, `formatMcMotd`, `renderMcStatus`, `showMcStatusError`, `syncMcStatusQueryOption`, `parseMcPort`, `mcDisplayHost`, `setMcStatusUrl`, `validateMcQueryPort`, `mcStatusQueryPort`, `abortMcStatus`, `checkMcStatus` and `loadMcStatusFromUrl`. The rest of the file is covered by scripts.md. The Go side of the page (the route, the share link markup and the embed) is in mcstatus.md.

The tests are in test/js/tests/mcstatus-page.spec.js, and each title starts with its row ID, so `--grep MP-07` runs one row. A row with several cases is a loop of tests, or one test that runs a table of cases when the function needs no lookup, and every title starts with the row ID. The API is `page.route` mocks of `{API}/mcstatus/**`, with the icon endpoint answered with a 1 pixel PNG. The mock adds the `host` and `port` the API would send, taken from the address as typed (the default port is 25565, and 19132 with `bedrock=true`). A function row calls the function on the loaded page with `page.evaluate`, and a flow row types in the form. Where a row says the lookup was answered with ONLINE, the answer is `{name: Hypixel Network, motd: §aHello\n§c§lWorld, version: Paper 1.21, num_players: 3, max_players: 20, players: [Alex, Steve]}`.
